## 구현 메모
- 변경한 파일: `functions/src/taskSuggestions.ts`, `functions/src/index.ts`, `functions/scripts/verify-task-model.mjs`, `apps/web/src/features/tasks/`의 모달·API·스타일, `apps/web/scripts/verify-live-chat.mjs`, README.
- 의사결정 및 이유: 사용자가 메시지에서 **업무 요청**을 연 뒤 **초안 제안받기**를 직접 누를 때만 제안 함수를 호출한다. 서버에서 워크스페이스 멤버십과 DM 참여 여부를 확인하고 선택한 메시지까지 같은 대화방의 최대 8개 메시지만 사용한다. 하루 사용자당 10회로 제한한다. 후보 선택은 공개 제목 입력만 채우며 저장은 별도 확인 버튼으로 한다.
- 발견한 문제/해결: 비공개 채널·DM 대화를 외부 OpenAI API로 전송하는 실행 경로가 자동 승인 검토에서 거부됐다. 외부 전송을 연결하지 않고 로컬 문장 기반 초안으로 기능 흐름을 검증했다. UI에도 AI 생성 결과가 아님을 표시한다.
- 검증: `npm run typecheck`, `npm run build:functions`, Auth·Firestore·Functions 에뮬레이터 권한/문맥 테스트와 두 Chrome 세션의 채널·DM 초안 선택·제목 편집·확정 저장 테스트 통과. 제안 선택 전후 업무 문서가 늘지 않는 것을 확인했다.
- 다음 일차에 넘길 사항: 외부 AI 전송에 대한 명시적 승인과 API 설정 후 실제 모델 응답·오류·비용 테스트. 그 전까지 19일차 AI 완료 기준은 미충족.

## 포트폴리오 기록
- 문제 정의: 메시지에서 직접 업무를 작성하는 흐름은 있지만 제안 후보를 요청하거나 편집할 수 없었다.
- 선택한 접근과 대안: 권한을 서버에서 재확인하고 같은 방의 제한된 문맥만 읽는다. 외부 전송은 승인 전까지 연결하지 않고 로컬 초안으로 UI 흐름을 완성했다.
- 검증 근거(수치 임의 생성 금지): 에뮬레이터에서 다른 워크스페이스·DM 접근 거부와 8개 문맥 제한을 확인했다. 두 Chrome 세션에서 명시적 버튼·후보 선택·제목 수정·저장 분리를 확인했다.
