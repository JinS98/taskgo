# Taskgo UI/UX 검토 시안

[상호작용 시안](taskgo-ui-preview.html)에서 Chat·Board·Calendar 탭, 워크스페이스 메뉴, 채팅 메시지의 **업무로 변환** 모달을 확인할 수 있다. 사용자가 승인한 밝은 테마와 2단 구조를 실제 React·SCSS 앱에 반영했다. 이 HTML은 비교용 시안이며 샘플 데이터만 사용한다. 실제 기능은 `npm run dev:all`로 실행한 앱에서 확인한다.

## 제안 팔레트

| 역할 | 색상 |
|---|---|
| 페이지 배경 | `#F5F6F9` |
| 카드·메인 화면 | `#FFFFFF` |
| 기본 텍스트 | `#202838` |
| 보조 텍스트 | `#677284` |
| 경계선 | `#E4E8EF` |
| 주요 액션 | `#5849C8` |
| 선택 배경 | `#F0EDFF` |
| 완료·진행 보조색 | `#187765` |

사이드바 264px, 상단 헤더 65px, 뷰 탭 51px의 2단 구조를 기준으로 했다. 카드 모서리는 9~15px, 주요 여백은 8·16·24·32px 계열로 맞췄다. 실제 앱의 월간 캘린더는 Firestore 업무 마감일을 표시하며 확정 업무를 단색 블록으로, 요청 대기를 점선 테두리로 구분한다. 팀 전체·내 담당·내가 요청한 검수 필요 업무를 필터링한다. 회의 일정은 아직 표시하지 않는다. 기존 사용 요청에 따라 실제 앱에서는 내 채팅 메시지를 오른쪽에 배치한다.
