# Taskgo 브랜드 가이드

- **서비스명:** Taskgo (태스크고)
- **로고 워드마크:** `t:go`
- **슬로건:** 대화가 업무가 되는 순간
- **앱 색상:** 밝은 페이지 배경 `#F5F6F9`, 흰색 화면 `#FFFFFF`, 기본 글자 `#202838`, 보조 글자 `#677284`, 경계선 `#E4E8EF`.
- **주요 액션:** 인디고 `#5849C8`, 선택 배경 `#F0EDFF`, 완료·진행 보조색 `#187765`.
- **의미:** 콜론(`:`)은 대화와 업무의 연결점을 상징한다.
- **앱 내 적용:** 브라우저 제목, 파비콘, 로그인·사이드바에 `t:go` 표기를 사용한다. 승인된 [UI 시안](design/README.md)의 밝은 테마와 글자·여백 규칙을 채팅·업무 보드·캘린더에 적용한다.
- **참고:** 상표·도메인 중복 검토 전의 브랜드 초안이다.
