# 제품 요구사항

## 핵심 목표
- Slack 스타일 워크스페이스·채널·DM 채팅.
- 메시지에서 명시적으로 '업무 생성' 선택 시 AI가 접근 권한 내 문맥을 분석해 **편집 가능한** 하나 또는 여러 업무 후보를 제안.
- 사용자가 최종 확인한 후에만 업무 요청 저장.
- 요청 시점부터 업무 제목·요청자·담당자·마감일·상태를 팀 전체에 공개. DM 원문은 참여자 외 비공개.
- 마감일 필수, 예상 작업 시간 선택. 업무 마감일을 실제 시간 점유 블록으로 간주하지 않음.

## 워크스페이스 생성·초대
- 워크스페이스를 만든 사용자가 워크스페이스 장이다. 장은 Firebase Authentication의 이메일·비밀번호 로그인 또는 Google 로그인을 선택할 수 있다.
- 워크스페이스 장은 대상의 이메일 주소로 초대 메일을 보낸다. 워크스페이스 생성과 초대는 별개이며, 초대 방식은 코드 입력보다 간단한 **이메일 전용 초대 링크**를 사용한다.
- 사이드바의 워크스페이스 관리 메뉴는 장에게만 보인다. 관리 본문에서 멤버 목록, 초대 현황, 초대 발송과 철회를 처리한다.
- 초대받은 사람은 링크를 열고 로그인하거나 가입한다. 확인된 로그인 이메일이 초대받은 이메일과 일치할 때만 워크스페이스에 가입한다. 로그인 방식이 달라도 기존 멤버십이 중복 생성되지 않도록 계정 연결·충돌을 처리한다.
- 초대 링크는 만료·철회가 가능하고 1회만 사용할 수 있다. 초대 권한과 가입 처리는 서버에서 검증하며, 링크를 여는 것만으로 멤버가 되지 않는다.

## 캘린더 필터
1. 팀 전체 일정
2. 내 담당 업무
3. 내가 검수할 업무

확정/미확정, 업무 마감/검수 마감/회의를 시각적으로 구분. 날짜 드래그는 변경 확정이 아닌 **제안** 시작.

## MVP 범위
워크스페이스 생성·이메일 초대·멤버 가입, 채널·DM, 업무 생성·수락·거절·마감 협의, 선택 검수·자동 완료, 보드·캘린더, 알림, AI 업무 추출.

## 범위 제외/후순위
마이크로서비스, Redis 기반 다중 소켓 서버, 고용량 파일/동영상 업로드, Java 전환, 비공개 업무.
